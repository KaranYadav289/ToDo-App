What is the ToDo Application?

ToDolist is a simple task manager that helps you write down what you need to do and keep it all in one place. Every task you add is saved in a database, so it is still there when you come back later. It is built with Flask, SQLAlchemy, and Bootstrap.

Features

📝
Add Tasks

Give each task a title and a short description.

🗂️
Saved Safely

Tasks are stored in a database and never disappear on refresh.

⏰
Time Stamps

See exactly when each task was created.

How to Use

1
Open the Home page. Click "Home" in the navigation bar.
2
Fill in the form. Type a title and a description for your task.
3
Click Submit. Your task is saved and the page reloads.
4
Update or delete. Use the buttons in the Actions column to edit or remove a task.
